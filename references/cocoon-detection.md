# 茧房判断 — 关注列表分析

> 你关注了谁，你就是谁。看看你自己的信息环境。

## 理论基础

概念来自 @tombkeeper（教主）的"关注列表定律"体系：

- **#1 归纳→演绎→迭代**：观察某类人共同关注了特定账号 → 发现某人也关注了这些 → 预判类型 → 验证修正
- **#2 机械式响应模型**：扫前 80 字 → 命中关键词 → 喷射预设话术 → 心理满足 → break（从不读完全文）
- **#3 老鼠屎隐喻**：一粒老鼠屎坏一锅粥——关注列表中少数问题账号足以定性整体
- **#4 吃屎隐喻**：一个人吃饭+吃屎=吃屎的人。"兼听则明"不是吃屎的理由
- **#8 粉丝修正算法**：建立"特征账号集" → 统计命中数 → 设阈值 → 触发标签

引用的十篇文章合辑：https://weibo.com/1401527553/5324176623931024

## 分析流程

### Step 1：拉取关注列表 + 筛选大V

只分析粉丝>1万或已认证的账号。素人号简介空泛，无法准确归类。

```python
big_vs = [f for f in friends if (f.get("followers_count") or 0) > 10000 or f.get("verified")]
```

### Step 2：品类归类（官方/行业维度）

基于大V的**用户名 + 简介 + 认证理由**（认证理由权重 ×2）关键词匹配：

| 品类 | 关键词 |
|------|--------|
| 军事/时政 | 军事、国防、武器、战略、战争、外交、政策、日报、通讯社、警察、法治 |
| 财经/投资 | 财经、金融、股票、投资、A股、基金、理财、经济、证券 |
| 科技/AI | 科技、AI、人工智能、代码、软件、大模型、互联网、程序员、数码、相机、评测、汽车…… |
| 影视/媒体 | 影视、电影、导演、摄影、摄像、DIT、调色、剪辑、后期、制片、特效、VFX、CG、摄影机、胶片…… |
| 生活/美食 | 美食、旅游、穿搭、家居、日常、搞笑、时尚、主播…… |
| 知识/教育 | 科普、教育、学术、读书、历史、文化、医生、教授、认知、老师…… |

无法归类的标为「其他」；命中样本按粉丝量倒序**人工复核一轮**后定稿。

### Step 2.5：平台官方账号剔除（工具关注，不参与评判）

**仅剔除微博/新浪平台自家账号**：昵称以「微博 / 新浪 / 超话」开头，或命中产品号集合 {粉丝头条官方微博, 头条文章, 大众评议小广播}。这些属于会员/活动/安全/抽奖等平台工具号，**不是信息偏好信号**，从大V池、品类分布、高危浓度、Top 榜单中全部移除。

**注意**：品牌/媒体/政府官号（如 人民日报、小米手机、索尼中国、漫威影业、上海发布）虽认证理由写"官方微博"，**切勿误剔**——判断词只能用昵称前缀/产品集合，不能用"官方微博"字样。

### Step 3：高危浓度层（横切维度，与品类正交）

> 实证观察：茧房重患者的关注列表里**大量**出现军事博主、财经博主、女权主义、动保组织、中医养生、伪科学/玄学账号。这些信号大多不属于官方认证分类，**必须靠简介/认证理由关键词辨别**。

高危人群旗标（对 name+description+verified_reason 匹配，命中即计入浓度）：

| 旗标 | 关键词（保守起步，命中需人工复核） |
|------|------|
| 军事/时政 | 复用 Step 2 品类结果 |
| 财经/投资 | 复用 Step 2 品类结果 |
| 女权/性别对立 | 女权、女性主义、性别对立、田园女权 |
| 动物保护 | 动保、动物保护、流浪动物、流浪猫狗救助、领养代替购买、TNR |
| 中医养生 | 中医、养生、经络、艾灸、药膳、老中医、排毒、祛湿 |
| 伪科学/玄学 | 阴谋论、玄学、风水、占卜、算命、星座运势、量子波动、磁疗、保健品、能量石、水素 |

**高危浓度** = 命中任一旗标的大V数 ÷ 大V总数。

### 平衡原则（核心纪律）

**关注 ≠ 问题，浓度才是信号。** 谁都关注几个军事号、几个养生号——单点关注是正常信息来源，大量聚集才是茧房墙砖。判定永远看组合：浓度 × 多样性 × Top2 占比，三者一起看，不做单指标定罪。

| 高危浓度 | 解读 |
|:--:|------|
| < 10% | 背景噪音，人人都有 |
| 10% – 30% | 偏好明显，但主粮还在 |
| 30% – 50% | 偏食，平衡正在倾斜 |
| ≥ 50% | 茧房信号 |

任一**单一旗标** > 25% 时单独点名预警（如"军事号占 28%"）。

### Step 4：成分标签（画像层）

| 标签 | 条件 |
|------|------|
| 「数字原住民」 | 科技/AI 占比 > 30% |
| 「战略家」 | 军事+财经 > 50% |
| 「饭圈居民」 | 娱乐 > 40% |
| 「生活家」 | 生活+美食 > 40% |
| 「知识控」 | 知识+媒体 > 40% |
| 「茧房居民」 | 前 2 品类 > 70% 且多样性 < 0.5 |
| 「杂食动物」 | 品类分布均匀，最大 < 20% |
| 「头部信徒」 | 百万粉以上 > 60% |
| 「独立思考者」 | 个人认证 > 40% 且多样性 > 0.6 |

### Step 5：信息多样性评分

```python
H = -Σ(p_i × log2(p_i))     # 信息熵
H_max = log2(N)               # 品类数
diversity = H / H_max         # 归一化 [0, 1]
```

| 评分 | 含义 |
|------|------|
| > 0.8 | 高度多样，信息来源丰富 |
| 0.5 – 0.8 | 中等多样，有一定偏向 |
| < 0.5 | 低多样性，茧房风险 |

### Step 6：判词（终审层 · 四层组装引擎 v1.1）

判词是报告的落款。**同一档位的人不能拿到一模一样的判词**——判定结果 = 母档(3) × 子档(3) × 品类血肉(13) × 措辞变体(3)，共 9×13×3 = **351 个不重复出口**。

**第一层 · 闭合度分数**（0~1，越高越封闭；只用于档内分带）：

```python
score = 0.35·min(top1/0.60, 1)          # 单一品类垄断
      + 0.25·min(top2/0.85, 1)          # 头部集中
      + 0.25·max((0.75-diversity)/0.75, 0)  # 多样性缺失
      + 0.15·min(risk_pct/0.50, 1)      # 高危浓度
```

**第二层 · 母档 = 硬规则优先，子档 = 分数分带**（v1.1 防误判关键：极端画像永远不会被分数"平均"到轻档）：

```python
# 母档硬规则（任一命中即定档，优先级从重到轻）
茧房: top1 ≥ 0.55 或 diversity < 0.35 或 risk ≥ 0.50 或 (top2 ≥ 0.75 且 diversity < 0.50)
偏食: top2 ≥ 0.50 或 diversity < 0.60 或 risk ≥ 0.25 或 top1 ≥ 0.35
平衡: 其余
# 档内子档分数带
茧房: ≥0.74 深茧 / ≥0.66 回音壁 / 其余 同温层；top1 ≥ 0.70 直接深茧（硬覆盖）
偏食: ≥0.56 重口偏食 / ≥0.46 偏食 / 其余 单一主粮
平衡: ≥0.26 有主粮的杂食 / ≥0.14 采样均衡 / 其余 杂食动物
```

**权重边界自查表**（改权重后必跑，`python3 scripts/verdict_engine.py` 自带）：

| 画像 | 应得判词 |
|------|---------|
| 军事 55% + 财经 25%，多样性 0.30，浓度 62% | 🔴 茧房·深茧 |
| 单一品类 90% | 🔴 茧房·深茧（硬覆盖，绝不允许落轻档） |
| 科技 54.4%，多样性 0.69，浓度 5.6% | 🟡 偏食·偏食 |
| 中医 40% + 玄学 20%，浓度 55% | 🔴 茧房·回音壁 |
| 最大品类 18%，多样性 0.88 | 🟢 平衡·采样均衡 |

**第三层 · 品类血肉**：取用户关注最多的品类（若某高危旗标——中医/玄学/女权/动保——占比超过主品类，判词改口指向旗标），注入该品类的意象对 `(A=TA 的世界, B=TA 的腔调)`。13 个品类各有专属意象（科技/AI=奇点前夜·万物皆可优化；军事=开战前夜·三句话不离博弈；中医=调理期·先祛湿再说别的……全表见 scripts/verdict_engine.py IMAGERY）。

**第四层 · 措辞变体**：每个子档 **3** 套骨架句（FRAMES），用 `(uid·31 + 主品类字符和·7 + 次品类字符和) mod 3` 确定性选取——混入次品类后，同档同主品类的两个人大概率也错开。撞词率：同(子档,主品类)内 1/3，全表 351 出口；同人重跑结果稳定（确定性，非随机）。

**判词示例**（同为茧房档，画像不同词不同）：

| 画像 | 判词 |
|------|------|
| 军事茧房 | 「你的关注列表只剩一种味道：一个永远在开战前夜的世界。三句话不离博弈和棋手——这不是你在看世界，是世界从你这里路过。」 |
| 养生茧房 | 「一个永远在调理期的世界——温度恒定、无人反驳。先祛湿，再说别的，在这里不是观点，是空气。」 |
| 科技偏食 | 「一个永远在奇点前夜的世界。菜单很厚，你总点这一道。看什么都想优化一遍——好吃，但别的味道正在消失。」 |

**规范实现**：`scripts/verdict_engine.py`（`judge(dist, diversity, risk_pct, flag_shares, uid)` → 结构化判词）。改阈值/加品类/换措辞只改这一处，报告生成器直接 import。改完必跑自测并对照上方边界自查表。
